## 🚀 Featured Projects

### 🎬 [TrackIt](https://github.com/KhaledAhmedElmasry/TrackIt): Film & TV Episode Tracker &nbsp;·&nbsp; *Solo*
<a href="https://track-itt.vercel.app"><img src="https://img.shields.io/badge/Live_Demo-track--itt.vercel.app-0EA5E9?style=flat-square" alt="Live demo" /></a>

A full-stack, installable PWA for tracking every film and episode you watch.
- Watchlists, per-season episode checklists and a read-only **offline mode**
- **TMDB** search and **Google Gemini** recommendations, plus daily **push notifications** for new episodes
- Revocable sessions, scrypt hashing, **AES-256-GCM** key encryption and Zod validation
- **CI** (lint, type-check, tests, build) and weekly encrypted DB backups with GitHub Actions

`Next.js` `React` `TypeScript` `Tailwind CSS` `MongoDB Atlas` `Vitest` `GitHub Actions` `Vercel`

- Built **Stripe** payments (payment intents, webhooks, refunds) and fare-difference flight changes
- Built auth with rotating refresh tokens, email verification, password reset and login lockout
- Backend API complete and documented in **Swagger**; Next.js frontend in progress

`NestJS` `TypeScript` `MongoDB` `Stripe` `Swagger` `Next.js`
